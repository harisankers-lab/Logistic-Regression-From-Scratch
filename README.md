# Logistic Regression From Scratch

This repository contains a beginner-friendly implementation of **Logistic Regression from scratch** using Python and NumPy.

The goal is to understand how Logistic Regression works internally, including the sigmoid function, probability calculation, gradient descent, and binary classification.

## Topics Covered

- Introduction to Logistic Regression
- Implementing the Sigmoid Function
- Probability Prediction
- Binary Classification
- Gradient Descent
- Updating Weights and Bias
- Making Predictions Using a Threshold
- Comparing Custom Implementation with Scikit-learn

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Google Colab

## Implementation

A custom Logistic Regression class is created with:

- `fit()` – Trains the model using gradient descent.
- `predict()` – Calculates the probability and predicts the class using a 0.5 threshold.

The custom implementation is also compared with Scikit-learn's Logistic Regression model to understand the differences in their predictions.

## Learning Objective

To understand the mathematical concepts behind Logistic Regression and gain practical experience implementing a machine learning algorithm without relying entirely on pre-built libraries.
